# SMART урок — Алгоритми з розгалуженням

Інтерактивний навчальний ресурс для учнів 7 класу з інформатики.

## Відкрити урок
Після увімкнення GitHub Pages: https://kifok.github.io/smart_lesson/

## Дидактична мета
Сформувати розуміння алгоритмів із розгалуженням, уміння визначати істинність умов, прогнозувати результат роботи програм та обирати коректні оператори порівняння Python.

## Структура
1. Інструкція учневі та очікувані результати.
2. Теорія: розгалуження if / else, код і блок-схема.
3. Тест із вибором відповіді.
4. Інтерактивний тренажер перевірки умов.
5. Завдання з вибору правильного правила.
6. Підсумковий результат і зворотний зв’язок.

## Технології
Самодостатній файл index.html з HTML, CSS і JavaScript, без зовнішніх бібліотек. Результати обчислюються локально у браузері.

## Публікація на GitHub Pages
У репозиторії відкрийте Settings → Pages → Build and deployment. Оберіть Deploy from a branch, гілку main, каталог /(root), потім Save.
