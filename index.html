02 · навчальний матеріал

Як працює розгалуження

Розгалуження — це алгоритмічна конструкція, у якій наступна дія залежить від істинності умови.

Наприклад, якщо температура нижча за 0 °C, програма повідомить «Мороз», інакше — «Немає морозу».

if temperature < 0: print("Мороз") else: print("Немає морозу")

Запам’ятай: якщо умова істинна, виконується блок після if. Якщо хибна — блок після else. Відступи у Python мають значення.

04 · інтерактивний елемент 2

Тренажер «Перевір умову»

Уведи число, спрогнозуй результат і перевір свою відповідь. Спробуй принаймні два значення — від’ємне і додатне.

if number >= 0: print("Невід’ємне") else: print("Від’ємне")
Алгоритм готовий до запуску.
